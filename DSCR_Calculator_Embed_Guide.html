🏠 DSCR Calculator - Embed Instructions

Developer guide for embedding the BrickWood Mortgage DSCR Calculator on your website

📋 Step 1: Get Your Streamlit URL

Before embedding, you need your calculator's URL:

  1. Go to share.streamlit.io
  2. Find your DSCR Calculator app
  3. Copy the full URL (example: https://devinday128-dscr-app-xyz.streamlit.app)
⚠️ Important: Replace YOUR_STREAMLIT_URL in all code examples below with your actual URL.

🎯 Option 1: Simple iframe (Recommended for Most Sites)

Best for: WordPress, Squarespace, Wix, Webflow, or any HTML page.

Code to Copy:

<iframe
  src="YOUR_STREAMLIT_URL?embedded=true"
  width="100%"
  height="900"
  style="border: none; border-radius: 8px;"
  title="DSCR Calculator"
  loading="lazy"
></iframe>
📝 Notes:
  • ?embedded=true removes the Streamlit toolbar for a cleaner look
  • Adjust height if content is cut off (try 1000-1200 for mobile)
  • loading="lazy" improves page load performance

📱 Option 3: Fully Responsive Embed

Best for: Mobile-optimized sites that need different heights on mobile vs desktop.

HTML + CSS Code:

<style>
  .dscr-calculator-wrapper {
    max-width: 1200px;
    margin: 2rem auto;
    padding: 0 1rem;
  }

  .dscr-calculator-frame {
    width: 100%;
    height: 950px;
    border: none;
    border-radius: 8px;
    box-shadow: 0 4px 20px rgba(0,0,0,0.1);
  }

  /* Mobile adjustments */
  @media (max-width: 768px) {
    .dscr-calculator-frame {
      height: 1200px; /* Taller for mobile */
    }
  }
</style>

<div class="dscr-calculator-wrapper">

  ></iframe>

🛠️ Troubleshooting

Calculator is cut off / not fully visible

Increase the height value in the iframe. Try:

  • Desktop: 900-1000px
  • Mobile: 1200-1400px

Calculator shows "Unable to load"

  • Verify your Streamlit URL is correct and the app is running
  • Check that the URL includes ?embedded=true
  • Make sure the Streamlit app is set to Public in settings

Calculator loads slowly

  • Keep the loading="lazy" attribute (loads when user scrolls to it)
  • Place the calculator lower on the page if possible
  • Consider adding a loading message while iframe loads

Scrolling issues on mobile

Add this attribute to your iframe:

scrolling="yes"
